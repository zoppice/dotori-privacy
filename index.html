개발자 책갈피책상

책갈피책상(이하 "개발자")은 도토리통장(이하 "앱")을 쓰는 가족의 개인정보를 소중히 여깁니다. 앱은 회원가입이 없고 인터넷으로 정보를 주고받지 않으며, 모든 정보는 앱을 쓰는 휴대폰 안에만 저장됩니다.

1. 앱에 저장되는 정보

부모님이 앱에 입력하는 아래 정보는 사용하는 기기 안에만 저장되며, 개발자를 포함해 누구에게도 전송되지 않습니다. 개발자는 이 정보를 볼 수도, 받을 수도 없습니다.

  • 아이 이름 또는 별명, 고른 캐릭터와 색
  • 넣기·꺼내기 기록과 메모, 예금·적금 정보
  • 부모님과 아이의 잠금(숫자 비밀번호 또는 패턴)
  • 부모님 생년월일
  • 화면 테마, 진동 같은 앱 설정

2. 정보를 쓰는 목적

  • 통장 잔액과 기록을 보여 주고 이자를 계산하기 위해 씁니다.
  • 잠금은 넣기·꺼내기와 설정을 바꿀 때 부모님(또는 아이) 본인인지 확인하는 데 씁니다.
  • 부모님 생년월일은 부모님 잠금을 잊었을 때 본인을 확인하고 잠금을 다시 정하는 데에만 씁니다.

3. 하지 않는 것

  • 회원가입, 로그인
  • 서버 저장, 인터넷 전송, 다른 사람이나 회사에 정보 제공
  • 광고, 광고 식별자 사용
  • 외부 분석 도구 사용
  • 위치, 카메라, 마이크, 연락처, 사진 접근

4. 보관 기간과 삭제

정보는 앱이 설치된 기기에 있는 동안 보관됩니다. 설정 탭의 부모님 메뉴에서 "모든 기록 지우기"를 누르거나 앱을 삭제하면 모든 정보가 지워지며 되돌릴 수 없습니다. 아이 통장 하나만 지우는 것도 부모님 메뉴에서 할 수 있습니다.

5. 어린이의 개인정보

앱은 만 14세 미만 어린이가 부모님과 함께 쓰도록 만들었습니다. 아이의 정보는 부모님이 직접 입력하고 관리하며, 개발자는 어린이의 정보를 수집하거나 외부로 보내지 않습니다. 넣기·꺼내기와 설정 변경에는 부모님 잠금 확인을 거칩니다.

6. 이용자의 권리

부모님은 언제든지 앱 안에서 정보를 직접 보고, 고치고, 지울 수 있습니다. 아이 이름과 그림은 부모님 메뉴의 아이 통장에서 고치고, 기록 전체는 "모든 기록 지우기"로 지웁니다.

7. 방침의 변경

이 방침이 바뀌면 앱 업데이트와 이 페이지를 통해 알려 드립니다.
